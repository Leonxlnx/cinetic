# cinetic media

Demo films and preview images for the [cinetic](https://github.com/Leonxlnx/cinetic) README. They live on this branch so that installing the skill (`npx skills add Leonxlnx/cinetic`, a shallow clone of `main`) stays small.

| File | What it is |
|---|---|
| `kiln-launch-teaser.mp4` | 25 s launch teaser, 1920x1080, 60 fps, with sound |
| `kiln-launch-teaser.gif` | 640 px excerpt: the first 9.5 s and the last 7 s |
| `quire-streaks-vertical.mp4` / `.gif` | 12 s vertical product video, 1080x1920, with sound |
| `ledgerly-feature-loop.mp4` / `.gif` | 10 s silent seamless feature loop, 1920x1080 |
| `halden-logo-sting.mp4` / `.gif` | 6 s logo sting with sound |
| `social-preview.png` | 1280x640 repository social preview |

Every film was made by an agent with a development snapshot of cinetic 1.0.0 (the Kiln teaser in evaluation round 6, the others in round 7) from the briefs in [`evals/evals.json`](https://github.com/Leonxlnx/cinetic/blob/main/evals/evals.json), then re-encoded for the web. MIT licensed, like the rest of the repository.
