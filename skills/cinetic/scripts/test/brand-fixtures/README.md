# brand.py fixtures (made in code, invented brands)

- `kit-a/`: a full kit: a three-part mark (`ledgerly-mark.svg`, ids on each part), a wordmark of two letter
  shapes (`ledgerly-wordmark.svg`), named colours with one second hue (`colours.json`). brand.test.py adds a
  screenshot PNG, a TTF face, an italic face and a woff2 face at test time.
- `kit-b/`: a logo only (`kestrel-logo.svg`, fills but no colours file): the colours are measured from it.
- `kit-dark/`: a dark-ground brand whose colours come as CSS custom properties (`brand-tokens.css`).
